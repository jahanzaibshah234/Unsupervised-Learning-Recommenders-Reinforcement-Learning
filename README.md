# Unsupervised Learning, Recommenders & Reinforcement Learning - Machine Learning Specialization ✅

This repository contains my code and projects from **Course 3 ("Unsupervised Learning, Recommenders, Reinforcement Learning")** of DeepLearning.AI's [Machine Learning Specialization](https://www.coursera.org/specializations/machine-learning-introduction).

## 🧠 Topics Covered ✅
- **Week 1**: Unsupervised Learning (Clustering, K-means intuition & algorithm)
- **Week 2**: Recommender Systems (Collaborative Filtering, Content-Based filtering,Principle Component Analysis)
- **Week 3**: Reinforcement Learning (Reinforcement learning, State-action value function, Continous state spaces)

## 💻 Projects ✅
Each week includes a hands-on lab or mini-project such as:
- Customer Segmentation using K-means
- Image Dimensionality Reduction with PCA
- Movie Recommendation System (Collaborative Filtering)

## 🛠 Technologies Used ✅
- **Python** (NumPy, Pandas, Matplotlib)
- **Scikit-learn**
